# c abi

version: 1

functions:

- `a2p_new`
- `a2p_call`
- `a2p_version`
- `a2p_free`
- `a2p_close`

rules:

- `a2p_call(handle, method, json)` returns a json envelope.
- returned strings are freed by `a2p_free`.
- `a2p_close` frees the handle and stops its sessions.
- the header is generated by cgo.
